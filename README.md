# 💫 Mayar Mohamed — Front-End Developer & UI/UX Designer Portfolio

A modern, high-performance, and visually engaging personal portfolio showcasing UI/UX case studies, interactive prototypes, and front-end engineering excellence.

---

## 🌟 Key Features & Highlights

### 🎨 Visual & Interactive Experience
- **Fluid Custom Cursor**: Smooth LERP-interpolated dual cursor with dynamic hover expansions on interactive components (automatically disabled on touch screens).
- **Interactive Canvas Particles**: Floating particle graph connecting dynamic nodes with distance calculations and mouse attraction physics.
- **3D Tilt & Dynamic Spotlight Cards**: Multi-dimensional perspective tilt effect that responds to cursor coordinates with realistic specular highlights.
- **Liquid Theme Switcher**: Animated radial expansion wipe transition between sleek Dark Theme and accessible Light Theme with `localStorage` persistence and system preference autodetection.
- **Glassmorphic Toast Notification System**: Non-blocking, modern notifications for user actions (form submissions, mockup interactions, accessibility toggles) replacing legacy browser `alert()` dialogs.

### 📱 Case Studies & Interactive Prototypes
- **Saree3 Car Rental App (UI/UX)**: Mobile application case study with interactive car selection playground, bidirectional swipe/slider with indicator dots, and keyboard navigation.
- **NurseConnect Telemedicine Portal**: Web dashboard case study with real-time consultation simulator and visual slide walkthrough.
- **Shefaa Elderly Care System**: Mobile app prioritizing WCAG accessibility, featuring an in-page accessibility sandbox (font size scaling and high-contrast toggle).
- **Jailak Dine-In Booking**: Interactive calendar, time slot selection, and table layout simulator.
- **Exam & Online Assessment**: Interactive quiz sandbox evaluating UX heuristics.
- **E-Commerce Platform**: Interactive mini-cart state demonstration.

### ♿ Accessibility & Modern Web Standards
- **WCAG AA Compliance**: High-contrast text palettes, full keyboard navigation with visible focus rings (`:focus-visible`), and a dedicated "Skip to main content" link.
- **Modern Semantic HTML5**: Accessible ARIA labels, semantic landmark elements (`<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`).
- **Responsive Architecture**: Fully responsive across mobile (<768px), tablet (768px - 1024px), and desktop (>1024px) viewports with lock-free touch scrolling.
- **Social & SEO Optimization**: Open Graph and Twitter card meta tags, and inline SVG favicon.

## 🚀 Getting Started

### Local Preview
Since the project is built with clean vanilla web standards, no build step is required!

1. Clone or download the repository:
   ```bash
   git clone https://github.com/MayarMohameed/Mayar-Portfolio.git
   ```
2. Open `index.html` directly in any modern browser, or launch a lightweight local server:
   - **Using VS Code**: Right-click `index.html` and select **Open with Live Server**.
   - **Using Node.js**:
     ```bash
     npx serve .
     ```
   - **Using Python**:
     ```bash
     python -m http.server 8000
     ```
